# Restaurant Billing System (Class 12 Computer Science Project)

A menu-driven restaurant billing application using Python and MySQL.

## Features

1. Display and search menu items.
2. Place an order and preview its bill.
3. Calculate GST/tax using preset or custom rates.
4. Store bills and item details in MySQL.
5. View previous bills and search by bill ID.
6. Add, update, and delete menu items.
7. View today's, monthly, or custom-date turnover.
8. Cancel a saved bill or discard the current unsaved order.

## Requirements

- Python 3
- MySQL Server
- mysql-connector-python

Install the connector:

~~~bash
python -m pip install mysql-connector-python
~~~

No other third-party Python packages are used.

## Database setup

### First-time setup

1. Start MySQL Server.
2. Open MySQL Workbench or the MySQL command-line client.
3. Run the contents of create_database.txt.

The script creates the restaurant database and the three tables:
menu, bills, and order_details. It inserts sample menu items.

### Existing database from the earlier version

The improved program lets MySQL generate each bill ID automatically. The old schema has a manually assigned bill_id, so run this migration once:

~~~sql
USE restaurant;
ALTER TABLE bills
    MODIFY bill_id INT NOT NULL AUTO_INCREMENT;
~~~

Alternatively, run migration_auto_bill_id.sql in MySQL Workbench.

This migration does not delete existing bills. MySQL will assign new IDs after the current maximum ID.

**Important:** database.sql is a MySQL dump that drops and recreates tables when imported. Do not import it over a database containing bills you need to keep. Use the migration above for an existing database.

## Configure the connection

By default the program connects to:

- Host: localhost
- User: root
- Database: restaurant

It asks for the MySQL password when it starts. You can optionally configure the connection using environment variables:

- MYSQL_HOST
- MYSQL_USER
- MYSQL_PASSWORD
- MYSQL_DATABASE

On Windows Command Prompt, for example:

~~~bat
set MYSQL_USER=root
set MYSQL_DATABASE=restaurant
set MYSQL_PASSWORD=your_mysql_password
python comp_project_class_12.py
~~~

Avoid saving a real database password in a public GitHub repository.

## Run the program

~~~bash
python comp_project_class_12.py
~~~

## Important behaviour

- A bill is saved together with all its order lines in one database transaction. If one insert fails, the transaction is rolled back.
- Bill IDs are generated by MySQL, preventing collisions from using MAX(bill_id) + 1.
- Currency and tax calculations use Python's Decimal type and round to two decimal places.
- Cancelling a saved bill changes its status to CANCELLED; it does not delete the bill or its items.
- Cancelled bills are excluded from turnover reports.
- A menu item that appears in an old order cannot be deleted because the foreign key protects billing history.
- The current unsaved order is held in memory and is lost if the program closes before the bill is stored.
